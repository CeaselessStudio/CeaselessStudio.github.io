For everyone / Для всех

/help

The commands any member can use, with no admin rights. Moderator commands stay hidden.

Команды, доступные любому участнику, без прав администратора. Команды модераторов в список не попадают.

/contract[member] [public]

Show a member's talent contract: tier, signing date (server join), roles. Defaults to yours.

Контракт участника: уровень подписки, дата подписания (вход на сервер), роли. По умолчанию - ваш.

Admin help / Админская помощь

Administrator / Администратор
/help-adm

Admin version of /help: moderator commands grouped by the right each one needs. Only administrators see it.

Админская версия /help: команды модераторов, сгруппированные по праву, которое для них нужно. Видна только администраторам.

Reaction roles / Роли по реакциям

Manage Roles / Управление ролями
/roles-cardcard

Post a reaction-role card in this channel: Languages (ten languages) or Teams (six teams). Members pick a role by reacting.

Поставить в канал карточку ролей по реакциям: Languages (десять языков) или Teams (шесть команд). Роль выбирается реакцией.

/roles-sync[apply]

Compare the cards with member roles: who reacted but has no role, who has a role without a reaction. apply: True fixes it.

Сверить карточки с ролями: у кого реакция без роли, у кого роль без реакции. С apply: True бот всё поправит.

Publishing / Публикации

Manage Server / Управление сервером
/say[channel] [image]

Send a message as the bot. A form opens for the text.

Отправить сообщение от имени бота. Текст вводится в открывшейся форме.

/embed[channel] [image]

Send a styled embed card (title, text, image) as the bot.

Отправить оформленную карточку (заголовок, текст, картинка) от имени бота.

/editmessage_link [image]

Edit a message the bot already sent. Right-click the message, then Copy Message Link.

Изменить уже отправленное ботом сообщение. ПКМ по сообщению, затем Копировать ссылку на сообщение.

Supporters / Поддержка

View Audit Log / Просмотр журнала аудита
/supporters[public]

Current Boosty / Patreon supporters, grouped by tier, with the date they joined and a CSV export.

Текущие подписчики Boosty / Patreon по уровням, с датой подписки и выгрузкой в CSV.

/roles-stats[days] [public]

Boosty / Patreon role changes from the stored history (days, 0 = all time, default 45), plus the conflict check and CSV.

Изменения ролей Boosty / Patreon из накопленной истории (days, 0 = всё время, по умолчанию 45), проверка конфликтов и CSV.

/languages-teams[public]

How many members hold each language and team role.

Сколько участников держат каждую языковую роль и роль команды.

Early access / Ранний доступ

Manage Server / Управление сервером
/release addname link date

Schedule a build link. The bot posts it in #booster-builds 3 days and in #rater-builds 1 day before the public release date (YYYY-MM-DD), at 14:00 Moscow time. The public post is up to the author.

Запланировать ссылку на сборку. Бот сам напишет её в #booster-builds за 3 дня и в #rater-builds за 1 день до даты публичного релиза date (ГГГГ-ММ-ДД), в 14:00 по Москве. Публичный пост делает автор.

/release list /release removename

Show what is scheduled and what has already gone out, or cancel a scheduled build. To change the date, remove it and add again.

Показать расписание и что уже отправлено, или отменить запланированную сборку. Чтобы поменять дату, удалите и добавьте заново.

Reports & Service / Отчёты и служебные

Manage Server / Управление сервером
/weekly-report

Preview this week's report: supporter changes, new members, activity. The full report posts itself every Monday at 10:00 Moscow time.

Предпросмотр отчёта за текущую неделю: изменения подписчиков, новые участники, активность. Полный отчёт выходит сам каждый понедельник в 10:00 по Москве.

/status

Post a live status card in this channel: ping, uptime, host, version, module count, errors, last role-log catch-up. It refreshes itself every 5 minutes; a new card replaces the old one.

Поставить в канал живую карточку статуса: пинг, аптайм, хост, версия, число модулей, ошибки, последний догон лога ролей. Обновляется сама каждые 5 минут; новая заменяет старую.

[ ] - optional. channel defaults to the current one. public: True shows the result to everyone, otherwise only to you.
[ ] - необязательный параметр. channel по умолчанию - текущий канал. public: True - результат увидят все, иначе только вы.
